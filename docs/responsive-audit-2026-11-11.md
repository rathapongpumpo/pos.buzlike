# Header และ responsive — 11 พฤศจิกายน 2026

สถานะ: **แก้ไขและตรวจใน local production build แล้ว** ที่ `http://localhost:3100/`

## ผลที่ส่งมอบ

- Header หน้าแรก: desktop เรียงโลโก้ เมนู และปุ่มบัญชีในแถวเดียว; ต่ำกว่า 1000 px ใช้ปุ่มเมนูที่เปิดรายการและปุ่มใช้งานเป็นสัดส่วน ไม่อาศัยการ wrap เมนูหลายแถว
- แสดงทางเข้าตามบัญชีที่เข้าสู่ระบบแล้ว ไม่มีลิงก์เข้าสู่ระบบซ้ำ; ตรวจเปิด/ปิดเมนู, Escape คืน focus และลิงก์ไปส่วนราคา
- ปรับขนาดหัวเรื่องหน้าแรก, grid และฟอร์มให้พอดีพื้นที่; ช่องกรอกบนมือถือใช้ 16 px; แท็บไม่บีบข้อความและมีความสูงอย่างน้อย 44 px บนมือถือ
- Tablet แนวตั้งช่วง 761–900 px ใช้แคตตาล็อก POS สามคอลัมน์และตะกร้าด้านล่าง เพื่อลดการบีบพื้นที่สินค้า
- ตารางเลื่อนเฉพาะภายใน ไม่ดันทั้งหน้า; รหัสสินค้า ตัวเลข และข้อมูลในเซลล์ไม่ถูกบีบแตกบรรทัด
- แก้หน้าเปิด–ปิดกะเมื่อมีข้อมูลจริง: แยกพื้นที่ปุ่ม/วันที่ และจัดการ์ดสรุปจอแคบให้ยอดเงินไม่ล้น
- แก้ใบเสร็จใน modal บนจอ 320 px ให้แสดงจำนวนเงินครบ; ขนาดกระดาษใน print stylesheet ยังคงเดิม
- แก้หน้า “ยืนยันอีเมล” ที่แถบบัญชีเคยเบียดฟอร์มให้แคบ จัดเรียงในแนวตั้งและรองรับอีเมลยาว; จัดแถบบัญชีหน้าตั้งร้านให้มีตำแหน่งชัดเจน
- เพิ่มชื่อปุ่มเมนูผู้ดูแลสำหรับ sidebar แบบไอคอน และย่อชื่อหัวแถบผู้ดูแลบนมือถือ

## ผลตรวจ

ใช้ Playwright Chromium แบบ headless โดยไม่เปิดหน้าต่าง browser ภายนอก ตรวจ DOM geometry ร่วมกับภาพหน้าจอ ความกว้าง **320, 360, 390, 600, 768, 820, 999, 1000, 1024, 1280, 1440 px**

| กลุ่ม | จำนวนกรณี | ผล |
|---|---:|---|
| หน้าในระบบ/เลือกร้าน/ตั้งร้าน/สมัครแพ็กเกจ/หน้าแรกหลังเข้าระบบ | 187 | ผ่าน |
| หน้าแรก/ราคา/login/register/กู้รหัส/ยืนยันอีเมล/คำเชิญ/QR ที่ไม่ถูกต้อง | 143 | ผ่าน |
| Modal เพิ่ม/แก้สินค้า หมวด ตัวเลือก วัตถุดิบ สูตร ปรับยอด โต๊ะ พนักงาน คำเชิญ สาขา กะ บิล คืนเงิน และสมัครแพ็กเกจ | 110 | ผ่าน |
| POS มีสินค้า, PIN พนักงาน, เงินสด/พร้อมเพย์/บัตร, ตั้งร้านและยืนยัน PIN, QR เมนู/ตะกร้า และ 404 | 60 | ผ่าน |
| Header ก่อน/หลังเข้าระบบ รวม keyboard และ anchor links | 22 | ผ่าน |
| คำเชิญพนักงานที่ใช้ได้จริง ก่อน/หลังเข้าระบบ และหน้าตั้ง/ยืนยัน PIN | 15 | ผ่าน |
| ผู้ดูแล 4 แท็บและ modal จัดการร้าน/ราคา/คูปอง | 63 | ผ่าน |
| ยืนยันอีเมลพร้อมบัญชีและอีเมลยาว | 5 | ผ่าน |
| **รวม** | **605** | **ไม่พบ overflow/การตัดปุ่มที่ยังค้างในกรณีตรวจ** |

ตรวจเพิ่มอีก 2 กรณีให้ตารางเลื่อนไปถึงคอลัมน์ท้ายได้ และรหัสสินค้าอยู่บรรทัดเดียวบน 320/768 px

- `npm test`: **66/66 ผ่าน**, ไม่ข้ามการทดสอบ
- `npm run typecheck` และ `npm run build`: ผ่าน
- หลังลบบัญชี/ร้าน/บิล/คำเชิญทดสอบและไฟล์ session: ธุรกิจ 17, ผู้ใช้ 18, สินค้า 151, บิล 28, ยอดขาย 2,485.00, สต็อก 7,504 ตรง baseline
